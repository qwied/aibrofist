## Эмодзи убраны
По всей игре вместо картинок-эмодзи стоят подписи:

| было | стало |
|---|---|
| `🛠` | Ред |
| `💬` | Чат |
| `👥 3` | Игроков: 3 |
| `🎭 Роль` | Роль: … |
| `⏱️ 12.4` | Время: 12.4 |
| `🪙` в счётчиках редактора | Монеты |
| `💀` | Смерти |
| `☠ ⤴ ⇄ ↻` в галочках | Яд, Батут, Двигается, Вращается |
| `✕ Выйти`, `← Меню` | Выйти, Меню |
| `⚠` в панели владельца | текст ошибки |

Убрана и старая кнопка «Sandbox» из игрового экрана — режима давно нет.

**Лайк и дизлайк оставлены** — это узнаваемые значки оценки, слова
на их месте выглядели бы хуже.

## Оценки в Maps Browser
У каждой карты появились те же кнопки, что и в браузере скинов:
👍 и 👎 со счётчиком. Свой голос подсвечивается, повторный клик по той
же кнопке снимает оценку — раньше в картах голос нельзя было забрать
обратно, в скинах уже было можно.

```
до голоса : лайков 0, мой голос 0
лайк      : likes 1, myVote 1
повторно  : myVote 0 (снялся)
дизлайк   : dislikes 1
```

## Пользовательское соглашение
При первом заходе на главную открывается окно с соглашением — **один раз
на устройство**. Пока не ответили, страница не листается.

В тексте перечислено конкретно, что обрабатывается: ник и пароль (хранится
зашифрованным), игровой прогресс, дата регистрации и последний вход,
IP-адрес (только для ограничения регистраций и выбора языка), настройки
языка и темы. Отдельно сказано, зачем это нужно, что данные не продаются
и рекламы нет, что хранится в браузере и как удалить свои материалы.

Согласие запоминается в браузере, а у вошедших игроков ещё и на сервере —
чтобы не спрашивать заново на другом устройстве:

```
до     : accepted false
принял : saved true
после  : accepted true, version 1
гость  : saved false (хранит браузер)
```

Текст на русском и английском, выбирается по языку интерфейса.
Если соглашение изменится, достаточно поднять `VERSION` в `consent.js` —
и вопрос зададут заново.
