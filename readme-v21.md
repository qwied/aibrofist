# AIBROFIST v21

## Скин виден в профиле и у друзей
`skinAvatar.js` подменяет аватарки на ту же фигуру, что рисуется в игре:

- иконка в шапке,
- большая картинка в профиле (во весь рост),
- строки списка друзей,
- таблица лидеров,
- авторы карт и скинов.

Ник для каждой картинки определяется по её окружению: из адреса страницы,
из соседней ссылки `users.html?name=…` или из явного `data-bf-name`.
Скины запрашиваются пачкой — новый эндпоинт `/skins/many?names=a,b,c`,
один запрос на весь список, до 60 ников за раз. Списки друзей
дорисовываются позже, поэтому следит `MutationObserver`.

В круглых иконках фигура во весь рост выглядела бы крошечной, поэтому
для них добавлена портретная рамка (`bust`): голова, головной убор и плечи
в квадрате. В профиле — по-прежнему во весь рост.

## Чат на телефоне
Причина была в одной строке:

```js
inp.addEventListener('blur', function () { typing = ''; inp.value = ''; });
```

На телефоне фокус теряется от любого касания по экрану и от появления
клавиатуры — и набранное сообщение стиралось прямо во время печати.
Теперь по `blur` черновик сохраняется, над головой он просто перестаёт
показываться до возврата в поле. Стереть — Escape.

Заодно касания по полю ввода больше не уходят в игровые обработчики
(они гасили событие и сбивали фокус), а кнопка «говорить» возвращает
курсор в конец черновика.

## Вкладка Skins в профиле
Раньше там всегда было `Skins (0)`: эндпоинты `/getSkins` и
`/getSkinsForList` были заглушками, отдававшими пустой список.
Теперь они отдают настоящие скины игроков, плюс заработали вендорные
кнопки: открытие картинки скина (`/usersSkins/<id>.png` отдаёт SVG),
удаление своего скина и оценка чужого.

```
формат для вендора: {"page":"1/1","count":3,"skins":[…]}
оценка чужого скина: code 0
оценка своего:       «Свой скин оценивать нельзя»
удаление чужого:     отказ
удаление своего:     ок, осталось 2
```

## Прочие находки
- `/getMapData` при просмотре карты из Maps Browser вызывался без `catch`:
  если сервер не ответит, страница молча зависала. Теперь показывает ошибку.
- То же с отправкой оценки карты.
- Необработанные отказы `fetch` при обрыве сети больше не сыпятся в консоль.
- Монеты в таблице лидеров показывались эмодзи — заменены на модель монеты.
