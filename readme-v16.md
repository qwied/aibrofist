# AIBROFIST v16

## Хитбоксы
Раньше столкновения считались по прямоугольнику вокруг объекта: круг ловил
за углы, треугольник был стеной, ротатор вращался только на картинке.
Теперь у каждого объекта настоящий многоугольник (`polyOf`), который
поворачивается вместе с ним. Круг — 16-угольник, ротатор берёт угол из
анимации, платформа считается по своей текущей позиции.

Движение разделено по осям: по X берётся ширина фигуры в полосе высоты
игрока, по Y — высота в полосе его ширины. Так работают и склоны:
по треугольнику игрок теперь поднимается, а не упирается. Уступы до 16 px
проходятся шагом.

Полосы поджаты на 2 px — без этого игрок, стоящий ровно на блоке, задевал
его боком и его выталкивало вбок. Этот баг нашёлся на прогоне физики.

Выделение в редакторе тоже по форме: повёрнутые и круглые объекты больше
не ловятся мимо картинки.

## Скольжение
`FRIC` было 0.78 — игрок ехал юзом после отпускания кнопки. Стало 0:
на земле останавливается мгновенно. В воздухе инерция осталась, иначе
ломается управление в прыжке. Проверено: после отпускания 0.00 px.

## Объекты по режимам
У каждого режима свой набор, в чужом режиме объект не существует —
ни в палитре, ни при загрузке карты, ни при публикации:

- **Прятки** — Укрытие, Ищущий
- **Игра на двоих** — Дверь, Кнопка, Рычаг
- **Гонка** — Чекпоинт, Финиш
- **Общие** — блок, круг, треугольник, текст, яд, шипы, батут, монета,
  платформа, ротатор, ворота, точка старта

При смене режима в редакторе лишние объекты убираются (Ctrl+Z вернёт).
Сервер проверяет то же самое и называет, что именно мешает.

## Цвета
Строительные объекты по умолчанию чёрные, как сам игрок. Опасные (яд,
шипы, ротатор) и служебные (монета, чекпоинт, финиш, ищущий) оставил
цветными намеренно: чёрные шипы на чёрном блоке игрок не заметит,
и карта станет нечестной.

## Монета
Вытащил `coin.png` из профиля игрока и поставил её везде — в игре
(с тем же вращением), в шапке, в ценах, в панели разработчика.

## Оптимизация и лимит
- Объекты разложены по сетке 260 px; в столкновениях перебираются только
  соседние, а не все 2000. Платформы и ротаторы учитываются отдельно.
- Рисуется только то, что попадает на экран.
- Многоугольники кешируются и пересчитываются лишь при изменении.
- Лимит **2000 объектов** во всех режимах: редактор не даёт добавить
  больше, сервер отклоняет карту. В панели редактора появился счётчик.

## Skin Editor
Аксессуары перерисованы: объём за счёт тёмных и светлых деталей, обводки,
более чистые силуэты. Корона с камнями, шлем с бликом, крылья с перьями,
худи со шнурками и карманом, панцирь с кольцами.
