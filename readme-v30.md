# AIBROFIST v30

## Объяснение связей механизмов вернулось
Но не в виде постоянной надписи на экране. Теперь это строка
**«Как связать? ▾»** в панели свойств, и появляется она только когда
выбраны **Ворота**, **Кнопка** или **Рычаг** — то есть ровно там, где
вопрос и возникает. Свёрнута по умолчанию, разворачивается по клику.

Внутри:

> 1. У **Ворот** задай **ID** — например `g1`.
> 2. У **Кнопки** или **Рычага** впиши тот же `g1` в поле **Цели**.
> 3. Нажми ▶ — ворота откроются от кнопки.
>
> Целей можно указать несколько через запятую: `g1,g2`.
> Кнопка держит, пока на ней стоят. Рычаг переключает насовсем.

Последние две строки — то, чего в старой справке не было, а спрашивают
про это чаще всего.

## Что осталось убранным
- строка «ЛКМ — рисовать · колесо — зум · Space+ЛКМ…» в редакторе;
- вкладка «Помощь» с горячими клавишами;
- подсказка управления в игре.

```

только у ворот/кнопки/рычага    : true
свёрнуто по умолчанию           : true
```
