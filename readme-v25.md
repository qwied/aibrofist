# AIBROFIST v25 — одна шапка и нормальные аватарки

## Верхнее меню
Причина мигания: **шапок было две**. На главной, в профиле, в Maps Browser
и Leaderboard рисовалась вендорная панель, которую ещё и правил
`topnav.js`; на Skin Editor, Skins Browser и Avatar — своя, из `shell.js`.
Отсюда разный вид, разный язык подписей и «то появляется, то исчезает».

Теперь панель **одна** и строится в `shell.js` на всех страницах:

```
AIBROFIST | Leaderboard · Map Editor · Skin Editor · Maps Browser ·
            Skins Browser · Avatar · Logs · Menu     🪙 0   [аватар]
```

- Вендорная шапка спрятана и стилем, и скриптом — если она попробует
  дорисоваться позже, её поймает наблюдатель.
- `topnav.js` отключён на всех страницах: он существовал только чтобы
  чинить вендорную панель.
- `nav.js` оставил лишь карточки режимов на главной. Раньше он тоже
  трогал шапку, и две системы навигации мешали друг другу.
- **Синие рамки вокруг Logs и Telegram пропали** — их рисовал вендорный
  список ссылок. Logs теперь обычный пункт в строке, Telegram переехал
  в «Menu» вместе с режимами игры.
- Меню и меню профиля открываются по клику, закрываются по клику мимо,
  на телефоне разворачиваются во всю ширину.

Редактор карт и игровой экран оставил без шапки — они на весь экран,
панель бы легла поверх холста. В редакторе внизу слева появилась
маленькая кнопка «← AIBROFIST» для возврата.

## Аватарки
Было две беды сразу: в профиле фигура распирала круглую рамку, а в
списках и шапке показывалась одна голова — по ней скин не узнать.

- **Везде показывается фигура целиком**, просто разного размера.
  Портретную обрезку убрал совсем.
- Контейнерам заданы размеры, картинка вписывается через
  `object-fit: contain` — больше ничего не растягивается.
- Профиль: 148 px, на телефоне 112 px. Шапка: 40 px.
  Списки друзей: 44 px. Таблица лидеров: 42 px.
- Скин-картинка владельца показывается как есть, без перерисовки в SVG.
