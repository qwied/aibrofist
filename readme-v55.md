# AIBROFIST v55

## Убрана синяя линия
Из стопки поверхности удалён третий слой — тонкая яркая линия на границе
поверхности и глубины. Осталось два слоя:

| слой | доля от стопки |
|---|---|
| полоса 1, самая светлая | 60% |
| полоса 2, светлая | 40% |
| тело, ровный цвет | до дна |

Освободившиеся 14% стопки поделены между двумя оставшимися полосами,
поэтому общая высота поверхности не изменилась — переход к телу просто
стал плавным, без акцента.

Всё остальное на месте: пологая длинная волна, пузырьки над водой, ровное
тело без градиента, оттенки от основного цвета жидкости.
