# AIBROFIST v14

## Модель персонажа
`skinRender.js` теперь рисует ровно того игрока, что в игре: круглая голова
диаметром в ширину тела, зазор `h*0.049`, дальше капсула. Никаких глаз, рта,
рук и ног — это был мой домысел, его убрал. Поверх силуэта ложатся только
аксессуары, рисунок на теле обрезается по капсуле и за силуэт не вылезает.

## Skin Editor
- 5 слотов: **цвет, голова, лицо, тело, за спиной**. Цвет персонажа меняется —
  14 вариантов.
- **Всё бесплатно**, цен в редакторе больше нет.
- Кнопка «Выложить в Skins Browser»: до **5 скинов в сутки**, **+10 🪙** за каждый.
  Повтор набора запрещён — сервер сравнивает комплект и называет, чей скин
  совпал, чтобы было понятно, что менять.

## Skins Browser (новая страница)
Сделан по образцу оригинала: фильтры по автору и названию, сортировка по дате
и рейтингу, обновление, постраничный вывод, сетка карточек.
На карточке — превью, **название, автор со ссылкой на профиль, рейтинг**
и кнопки 👍 / 👎. Повторный клик снимает оценку, свой скин оценивать нельзя.
Кнопка «Примерить» надевает чужой скин.

## Avatar
Витрина скинов, которые владелец отобрал из Skins Browser.
На каждой карточке **указан автор**. Цена ставится владельцем; бесплатные
надеваются сразу, платные сначала покупаются. Слева видно, чей скин на вас надет.

## Панель разработчика
- **Добавить в игру** — теперь по кнопке на каждый режим (Прятки, На двоих,
  Гонка, Песочница). Клик добавляет, повторный убирает. Одна карта может быть
  сразу в нескольких режимах.
- В Skins Browser у владельца на карточке появляется поле цены и кнопка
  **«В Avatar» / «Убрать из Avatar»**.
- Панель по-прежнему приходит только владельцу: `owner.js` посторонним
  отдаётся пустым файлом.

## Мобильная вёрстка
- Пропал дубль «Таблица лидеров»: `topnav.js` сверял текст кнопки со словом
  `leaderboard`, а к тому моменту он был уже переведён. Теперь сверка идёт
  по `data-i18n`.
- Шапка: три зоны, ссылки прокручиваются горизонтально, меню профиля и
  подменю больше не уезжают за экран.
- Maps Browser на телефоне: таблица превращается в карточки — название,
  рейтинг, автор, дата, кнопки в отдельной строке.
- Редактор: панель инструментов прокручивается, кнопка владельца поднята
  над ней.
- Поля ввода 16px, чтобы iOS не зумил страницу; кнопки не меньше 40px.
- Свои страницы (Skin Editor, Skins Browser, Avatar) собраны на общих
  `ui.css` + `shell.js` — одинаковая шапка и сетка на телефоне и компьютере.
