# AIBROFIST v26

## Огромный скин в профиле — моя ошибка
Я сам её и внёс в прошлой версии. В `skinAvatar.js` картинке
проставлялись **строчные** стили `width:100%; height:100%`. Строчный
стиль перебивает любой CSS, а у обёртки профиля своей ширины нет —
поэтому фигура растянулась на весь экран.

Размеры больше не ставятся из скрипта, только `object-fit: contain`.
Размер задаёт CSS отдельно для каждого места:

| где | размер |
|---|---|
| профиль | 132 px (телефон 104) |
| шапка | 36 px |
| список друзей | 44 px |
| таблица лидеров | 42 px |

Заодно снял вендорный `clip: rect(...)` с `.profile-picture` — он
работает только для `position:absolute` и только мешал.

## Превью в Skin Editor больше не едет
У блока превью стоял `position: sticky` — он специально прилипал
к верху при прокрутке. Выглядело как баг, поэтому убрал: и в
Skin Editor, и на странице Avatar.

## Точная оценка карты вместо накрутки
Раньше числа были *прибавкой* к живым голосам. Теперь владелец
задаёт **итог**, который увидят игроки: сервер считает реальные
голоса и подбирает поправку сам. Новые голоса продолжают
добавляться поверх.

```
после 2 живых лайков: 2 / 0
ставим 500 / 3   → на карточке ровно 500 / 3
новый живой лайк → 501 / 3
ставим 0 / 0     → 0 / 0 (в минус не уходит)
чужой аккаунт    → Недоступно
```

## Удаление карт
- **В Maps Browser удалять может только владелец** — красная кнопка
  «🗑 Удалить» у каждой карты, с подтверждением по второму нажатию.
- **В своём профиле каждый удаляет свои карты**, как и раньше.
- Чужую карту из профиля удалить нельзя.

```
Petya удаляет чужую (Maps Browser): Недоступно
Petya удаляет чужую (старый путь) : Можно удалять только свои карты
Vasya удаляет свою в профиле      : success
System удаляет чужую              : «MapA» удалена
```

## Кнопки «Из файла» и «Из ссылки»
Теперь видно, что они нажаты: выбранная подсвечивается синим.
Под кнопками появилась строка состояния — «Читаю файл…», «Файл
загружен: имя.png», «Ссылка принята», «Готово — скин в Skins Browser».
Картинка встаёт на превью сразу, до публикации.

Панель по-прежнему приходит только владельцу: `owner.js` остальным
отдаётся пустым файлом.
