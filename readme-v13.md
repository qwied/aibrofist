# AIBROFIST v13

## Кнопки разработчика полностью скрыты

`owner.js` сервер отдаёт **только владельцу**. Всем остальным — гостям и обычным
игрокам — приходит пустой файл `/* */`.

Это значит, что у постороннего в браузере нет:
- ни кнопки 🛠, ни кнопок «Добавить в игру» и «Оценки» в Maps Browser;
- ни разметки панели, ни её стилей;
- ни адресов служебных запросов (`/owner/giveCoins`, `/owner/setVotes`,
  `/owner/mapInGame`) — их даже не видно в исходниках страницы.

Панель «Управление» в Settings тоже переехала в `owner.js`, поэтому в `account.js`,
который грузят все, её кода больше нет.

`/whoAmI` не раскрывает ник владельца посторонним: поле `ownerName` приходит
только самому владельцу.

Сервер всё равно проверяет права заново на каждом запросе (`ownerOnly`) — скрытие
кнопок это удобство, а не защита.

## Остальное в сборке

**Skin Editor** (`skinEditor.html`) — 50 вещей в 7 слотах: цвет тела, голова, лицо,
тело, руки, ноги, за спиной. Покупка за монеты, 9 базовых бесплатны. Персонаж
рисуется на SVG (`skinRender.js`) — один код в редакторе, на аватаре и в магазине.
Цены и списание считает сервер (`skins.js`).

**Автоперевод** — 10 языков (ru, en, uk, de, fr, es, pt, pl, tr, zh).
Порядок: выбор в Settings → страна по IP из заголовка прокси → `Accept-Language`
→ часовой пояс. Без внешних API. `MutationObserver` дописывает перевод в интерфейс,
который рисуют вендорные бандлы.

**Menu** — обработчик висел дважды и меню закрывалось сразу после открытия.
Теперь им управляет только `nav.js`; добавлены Skin Editor, Logs, Leaderboards,
на узких экранах Menu не прячется.

**Владелец** — ник `AIBrofist`, ник `System` тоже даёт права.
Меняется через `OWNER_NAME` и `OWNER_ALIASES`.
Доступно: добавление карты в игровые режимы, накрутка лайков/дизлайков любым
числом, выдача монет в любой профиль.

**Лимит монет** — 3 на карту. Редактор не даёт поставить четвёртую, сервер
пересчитывает монеты при публикации и отклоняет карту.
