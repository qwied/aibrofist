# AIBROFIST v44

## Жидкости перерисованы
Раньше рой частиц размывался мягкими пятнами и складывался по плотности.
На маленьких объёмах это давало круглые кляксы, висящие в воздухе и
никак не связанные с тем, что налил игрок.

Теперь тело жидкости — **ровно те клетки, которые налили**.

- **Заливка** идёт по самим клеткам, поэтому форма совпадает с нарисованной,
  а не сжимается в шар.
- **Край чёткий**: тонкий контур в 1.4 пикселя, и только по открытым граням.
  Внутренние стыки между соседними клетками не обводятся, иначе объём
  выглядел бы разлинованным.
- **Поверхность ровная**, с волной поверх открытых сверху граней. Ряд из
  трёх клеток даёт одну сплошную волну, а не три горбика.
- **Градиент** считается на весь объём разом: сверху светлее, ко дну темнее.

Частицы никуда не делись — они ушли внутрь. Их видно как медленные
течения под поверхностью, обрезанные по объёму, поэтому наружу ничего
не вылезает.

### Приметы жидкостей
Всё поверх тела и внутри обрезки:

| примета | у кого | что это |
|---|---|---|
| блик | ртуть, нефть, вода | светлая полоса у поверхности |
| прожилки | лава, кислота | живые жилы, пульсируют по времени |
| зерно | зыбучий песок | мелкие тёмные точки |
| пузырьки | прозрачные жидкости | всплывают снизу вверх |

Плотность у каждой своя: прозрачная вода 0.72, глухая ртуть и смола 1.0.

Приёмы те же, что у остальных объектов — плоская заливка, мягкий
градиент, тонкий контур. Жидкость читается своим материалом, но из
общего вида карты не выпадает.

### Что убрано
Отрисовка через отдельный холст, мягкие пятна и порог по плотности
больше не нужны: `blobSprite`, `wcv`, `wcx` удалены. Кадр стал легче,
на 700 частицах физика занимает 1.3 мс.
