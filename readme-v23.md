# AIBROFIST v23

## Владелец — System
`OWNER_NAME` теперь по умолчанию `System`, псевдоним `AIBrofist` тоже
работает. Меняется переменными окружения `OWNER_NAME` и `OWNER_ALIASES`.

## Инструменты владельца в Skins Browser
Раньше эта панель лежала прямо в `skinsBrowser.html` и просто пряталась
через `display:none` — код и адреса запросов видел любой, кто открывал
исходник. Теперь она целиком в `owner.js`, а этот файл сервер отдаёт
только владельцу; остальным приходит пустой `/* */`.

Что доступно владельцу и никому больше:

- **Накрутка лайков и дизлайков** — два поля прямо на карточке скина,
  любое число.
- **Скин из любой картинки** — файлом с телефона или ссылкой из интернета.
- **Замена картинки** у уже существующего скина.
- Цена и выкладывание в Avatar, удаление любого скина.

```
владелец System: true          обычный игрок: false
owner.js  System: файл         Vasya: /* */
скин из картинки  System: success   Vasya: Недоступно   гость: Недоступно
накрутка оценок   System: 5000/7    Vasya: Недоступно
```

## Как устроена загрузка картинок
Раньше картинка хранилась строкой прямо в базе — data URL на сотни
килобайт в JSON, а ссылка из интернета просто запоминалась и грузилась
с чужого сервера. Теперь:

- файл ужимается в браузере до 300×450 и уходит на сервер;
- ссылка **скачивается сервером** и кладётся файлом в `data/skinimg/`,
  так что картинка не исчезнет вместе с чужим сайтом;
- проверяются тип (png, jpeg, gif, webp, svg) и размер (до 3 МБ);
- ссылки на локальную сеть запрещены — иначе сервер можно было бы
  заставить ходить по внутренним адресам:

```
не картинка : Такой формат картинки не поддерживается
локальный ip: Ссылки на локальную сеть запрещены
не адрес    : Нужна ссылка http или https
```

Такой скин виден везде: в браузере скинов, на аватарке, в профиле
и в самой игре — фигура заменяется картинкой целиком.

## Кнопки на телефоне
- **Минимум 44 px** у всех кнопок, чипов, вкладок и пунктов меню.
  Часть была 28–34 px, по ним промахивались.
- Убрана серая вспышка Android, добавлена подсветка нажатия — без
  наведения мышью иначе непонятно, сработало ли.
- **Книжная ориентация**: фильтры в две колонки, кнопка действия на всю
  ширину, запас снизу под панели.
- **Альбомная ориентация**: высоты почти нет, поэтому шапка ужата до
  44 px, отступы уменьшены, а меню, подменю и список разделов
  прокручиваются, а не уезжают за экран. Сетка карточек шире —
  меньше прокрутки.
- Экраны уже 360 px: карточки в одну колонку.

Проверка:

```
Все интерактивные элементы получили минимум 44 px.
книжная ориентация: есть
альбомная ориентация: есть
меню прокручивается в альбомной: да
```
