# AIBROFIST v33 — иконка сайта

## Что появилось
В браузерной вкладке вместо серого глобуса теперь логотип AIBrofist —
та же фигура игрока: круглая голова и капсула-тело.

Файлы:

| файл | для чего |
|---|---|
| `favicon.ico` | вкладка браузера, внутри сразу 16, 32 и 48 px |
| `favicon.svg` | экраны с высокой плотностью, масштабируется без потерь |
| `apple-touch-icon.png` | ярлык на домашнем экране iPhone, 180 px |
| `icon-192.png`, `icon-512.png` | Android и установка как приложение |
| `site.webmanifest` | название, цвет темы, иконки для установки |

Подключено на всех 14 страницах:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#111827">
```

`/favicon.ico` отдаётся отдельным маршрутом с недельным кэшем: браузер
просит его ещё до загрузки страницы, и это должно работать даже там,
где до статики дело не дошло.

## Про рисунок
Первый вариант при уменьшении читался как две точки — тело было
слишком круглым. Пропорции подогнал ближе к игровой фигуре: тело выше,
углы мягкие, но не круг. Проверил на 16, 32, 48, 64 и 96 px — знак
различим на самом мелком.

Иконка нарисована на белой скруглённой подложке, а не прозрачной:
на тёмной панели вкладок чёрная фигура без фона была бы не видна.
