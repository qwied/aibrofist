# AIBROFIST v24 — картинка прямо в Skin Editor

## Как это работает
Под превью в Skin Editor появилась панель (**только у владельца**):

- поле «Название скина»
- поле для ссылки на картинку
- кнопки «Выбрать файл» и «Взять по ссылке»
- кнопка «Опубликовать»

Выбрали файл или вставили ссылку — **картинка сразу встаёт на превью
вместо фигуры**, видно, что получится. Нажали «Опубликовать» — скин
уходит в Skins Browser, и его видят все игроки: могут примерить,
оценить, а вы можете выложить его в Avatar с ценой.

Файл ужимается в браузере до 300×450, ссылка скачивается сервером
и кладётся файлом в `data/skinimg/` — картинка не пропадёт вместе
с чужим сайтом.

## Почему панель не видна игрокам
Она живёт в `owner.js`, а сервер отдаёт этот файл только владельцу —
остальным приходит пустой `/* */`. У обычного игрока в исходнике
страницы нет ни разметки панели, ни адресов запросов. Сервер всё
равно проверяет права заново на каждый запрос:

```
владелец публикует картинку: success | файл: /skinimg/smtezlqv12wt.png
скин виден обычному игроку : «Мой арт» (/skinimg/…png)
надел — видят все           : /skinimg/…png
обычный игрок публикует     : Недоступно
```

## Мелочи в редакторе
- Превью умеет показывать скин-картинку — раньше оно всегда рисовало
  фигуру, даже если надет скин из картинки.
- Выбор любой детали, «Случайный образ» и «Сбросить» снимают картинку:
  иначе было бы непонятно, что именно редактируешь.
- При входе редактор подхватывает надетую картинку из каталога.

## Ещё
В панели 🛠 появилась кнопка «Открыть Skins Browser» с подсказкой,
где искать накрутку оценок и работу с чужими скинами.
