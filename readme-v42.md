# AIBROFIST v42

## Разбор запроса по словам
Заготовленных фраз больше нет. Текст режется на слова, и **каждое слово**
получает роль. Поиск идёт по корню, поэтому любая форма подходит:
«треугольник», «треугольниками», «треугольных» — одно и то же.

Роль выбирается по самому длинному совпадению во всех словарях сразу,
а не по порядку таблиц. Иначе «ядовитые» поймалось бы на корень «яд» и
стало объектом «вода» вместо свойства. Короткие служебные слова («а»,
«по», «в») сверяются целиком, иначе «а» съедало бы «абракадабру», а «по» —
«посередине».

### Что понимает

| роль | примеры |
|---|---|
| объект | блок, кубик, стена, платформа, пол, круг, шар, треугольник, шип, надпись, монета, вода, озеро, яд, старт, кнопка, рычаг, чекпоинт, финиш, выход |
| количество | цифрами и словами: 12, три, двенадцать, пара, несколько, много, куча |
| цвет | красный, оранжевый, жёлтый, зелёный, бирюзовый, синий, фиолетовый, розовый, коричневый, чёрный, белый, серый |
| размер | крошечный, маленький, большой, огромный, гигантский |
| место | сверху, снизу, слева, справа, в центре, по краям, вразброс |
| свойство | ядовитый, проходимый, укрытие, рикошет, движущийся, вращающийся, открытый, кислота, затягивающий |
| скорость | быстрый, медленный |
| направление | по горизонтали, по вертикали |
| основа карты | лабиринт, башня, арена, паркур, пещера, город, острова, мост |

Покрыты **все** объекты редактора и **все** их свойства.

### Отчёт
После разбора выводится, как понято каждое слово, и отдельно — список
непонятых. Ничего не теряется молча:

```
· 12 → количество: 12
· красных → цвет: #ef4444
· вращающихся → свойство: вращается
· треугольников → объект: треугольник
· сверху → место: сверху
· зюзюка → не понял

Буду ставить:
· 12 × треугольник, цвет #ef4444, вращается, сверху
```

### Как собирается фраза
Определения в русском стоят перед существительным, поэтому цвет, размер,
свойство и скорость копятся и достаются следующему объекту. Место обычно
идёт после — оно цепляется к уже названному объекту. Второе упоминание
того же объекта без своих числа и цвета считается уточнением: «синяя вода
снизу с ядом» даёт один объём, а не два.

Единственное и множественное число различаются по окончанию: «платформа»
это одна штука, «платформы» — несколько.

### Пределы
Потолок генератора поднят с 600 до 1900 объектов (у движка 2000).
Количество в одном заказе — до 400. Монет по-прежнему максимум три:
это правило сервера против накрутки, обойти его нельзя.

## Вода
Налив вернулся к прежнему поведению: вода ложится ровно там, где ведёшь
мышью, и держится на месте — вниз не стекает и из нарисованного объёма не
утекает.

Физика плавания не тронута совсем: скорость под водой, выталкивание,
воздух на 10 секунд, урон, кислота и затягивание работают как в v41.
